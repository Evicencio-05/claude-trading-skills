# TradeWhisperer Smart Candle Colors

Source: Patreon tutorial *How to read our proprietary smart algorithm candles* (Sep 5, 2024).

## Primary colors

| Color | Meaning |
|-------|---------|
| **Blue** | Potential **start** of a bullish trend |
| **Green** | **Continuation** of a bullish trend |
| **Pink** | Potential **start** of a bearish trend |
| **Red** | **Continuation** of a bearish trend |
| **Yellowish green** (TRIM-OPTION) | Optional **trim** — sharp rise + stalling momentum |
| **Dark green / Dark red** | Consolidation / “exchange of hands” |

## Confirmations

| Sequence | Meaning |
|----------|---------|
| Blue → Green | Bullish start confirmed |
| Pink → Red | Bearish start confirmed |
| Blue → Pink | Cancel → dark red |
| Pink → Blue | Cancel → dark green |
| Blue → Green → Pink | False breakout risk |

Higher timeframe dominates (monthly > weekly > daily). Lists map BLUE-GREEN / PINK-RED to confirmation stacks.
