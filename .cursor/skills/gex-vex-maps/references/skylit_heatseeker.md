## Anatomy

Rows = strikes (ATM highlighted); columns = expirations; cells = `$NK` exposure. Yellow+★ often top magnitude (hint only).

| Color | Typical | Behavior |
|-------|---------|----------|
| Green → Yellow | Positive | Lower-vol / absorb / pin |
| Blue → Purple | Negative | Higher-vol / wicky / overshoot |

**King Node** = highest **|value|** (can be purple). **Gatekeepers** block path to King. Prefer untouched nodes; avoid midpoints; fade range edges with price confirmation. **GEX∩VEX** overlap = confluence. VEX often better for multi-day bias.

## Five-step read

1. Magnets 2. King 3. Range edges 4. Gatekeepers 5. Flow/reshuffle (needs multi-shot)
