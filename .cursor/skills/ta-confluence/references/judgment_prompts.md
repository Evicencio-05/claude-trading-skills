# Judgment / Coaching Templates

Use after confluence scoring. Stress-test the operator’s read — do not cheerlead weak setups.

## Devil’s advocate (require 2–3)

Fill concretely from the artifacts:

1. **Color risk:** What TW list color / HTF stack (`tw_stack`) invalidates the bias within 1–3 bars? Prefer list colors over chart-inferred.
2. **Map risk:** Which king/gatekeeper/air-pocket could trap or reverse the move?
3. **Chart risk:** Which SMA / fib / VP shelf / S/R makes R:R fail if tagged?

## Invalidation (require before PLAY)

Write one kill condition in each domain when data exists:

| Domain | Template |
|--------|----------|
| TW | `Invalid if period list prints {COLOR} or HTF stack flips to {STACK}` |
| Maps | `Invalid if king migrates to {strike} / upside ceiling rolls to {strike}` |
| Operator | `Invalid on daily close beyond {price} (S/R|fib|SMA|VP)` |

If a domain is missing, say so — do not invent.

## Not allowed to ignore

List 1–3 facts the operator must acknowledge (examples):

- Daily BLUE under weekly RED stack
- GEX king above while VEX king fights
- Price mid VP shelf with 50/100 SMA sandwich and no edge
- TRIM_OPTION mistaken for new long entry

## R:R sketch

From **operator levels + map magnets only**:

- Entry zone (not a single tick unless obvious)
- Stop / invalidation price
- Target 1 (nearest opposing magnet / fib / shelf)
- Rough R:R — if unclear or ~1:1 midrange → do not force PLAY

## Process grade

Score honestly:

| Check | Pass? |
|-------|-------|
| Period **list** color present (not chart-only) | Y/N |
| HTF stack checked (`tw_stack` / weekly+monthly lists or htf_absent) | Y/N |
| Both GEX and VEX present (or gap noted) | Y/N |
| Operator chart present | Y/N |
| List vs chart color conflict noted (list wins) | Y/N/NA |
| Conflicts surfaced before verdict | Y/N |
| Override used? | Y/N + reason |

End with one line: **Process: solid / rushed / incomplete**.

## One thing to verify

Single sentence: the chart/map/candle detail the operator is most likely overweighting (recency bias, yellow star ≠ king, lime vs trim, etc.).

## NO_TRADE framing

When verdict is NO_TRADE, state it as disciplined process — not failure. Offer what would upgrade to WATCH/PLAY (e.g. weekly BLUE confirm, map reshuffle, reclaim of fib 0.786).
